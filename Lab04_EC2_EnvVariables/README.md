I think the reason you should not commit a .env file to Git is because it can contain important configuration values and sometimes sensitive information. Even in the case in which the repository is private, the information could still get exposed if the repo is shared or someone else gets access to it. It's safer to keep the .env file only on the system where it is being used and add it to .gitignore so Git does not track it. Instead, a .env.example file can be used to show what variables are needed without showing the actual values.
