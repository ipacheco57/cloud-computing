## Reflection
The Root user MFA is important to cloud security, due to the root account has full access to everything in the AWS account including billing and security settings. In the worst case if someone gained access to the root account, they could make major changes or cause unexpected charges. Having MFA enabled adds another layer of protection by requiring a second form of verification in addition to a password. Following the principle of least privilege it also is important to cloud security because it only allows for the least amount of access in addition to time with said access to complete a task. Which using an IAM follows the principle.
